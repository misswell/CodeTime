# CodeTime 1.0.0 Beta 2

**这是开发者预览版，不是稳定版。不要把 CodeTime 作为唯一的代码备份。**

相对 Beta 1，Beta 2 完成了三轮可靠性整改（CT-001…CT-069），覆盖云端垃圾回收、
任务租约、数据迁移、仓库发现、Keychain 恢复与发布门禁。自动化测试从 17 项扩展到
92 项，回归门禁要求全部用例在册且 0 失败。

支持 macOS 14+，本包为 arm64 + x86_64 universal，内置 Kopia 0.23.1。
本包同时提供 `.zip` 与 `.dmg`（拖拽安装）两种格式。

## 安装

1. 下载 `CodeTime-1.0.0-beta.2-macos-universal.dmg`（或 `.zip`）。
2. 将 `CodeTime.app` 拖到「应用程序」。
3. 首次打开如被 Gatekeeper 拦截：右键 →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeTime.app
   ```

4. 首次启动会生成恢复密钥。请立即离线保存；丢失它且 Keychain 不可用时，备份无法解密。

## Beta 1 → Beta 2 修复（按轮次）

### 第一轮整改（CT-001…CT-044，v1.0.0 可靠性大改）

- 云端 GC 持久化日志与墓碑：中断可恢复，aborted 不删对象。
- 上传确认 fail-closed：iCloud 元数据读取失败不再视为“已上传”。
- 对象 SHA-256 强校验：同大小不同内容被拒绝。
- SQLite schema v2：任务租约、项目生命周期、访问状态。
- 快照列表按最新在前；跨项目恢复被拒绝。

### 第二轮整改（CT-045…CT-057）

- Beta → Release 数据迁移：staging + 校验 + 整根原子替换。
- 恢复任务 committing 状态可续传；部分恢复文件自动替换。
- 多设备恢复严格绑定所选 deviceID；候选对象缺失时不可恢复。
- 本地仓库重新发现：SQLite 丢失不会新建空仓库覆盖旧数据。
- iCloud 镜像目录作为项目目录明确拒绝。

### 第三轮整改（CT-058…CT-069）

- 双 Mac iCloud 验收门禁硬化：模板/占位符/FAIL 行/tag+commit 不匹配全部拒绝。
- 仓库发现 fail-closed：已登记仓库丢失时永不自动切换；SQLite+Keychain 双丢失
  不会静默生成新密钥，进入恢复密钥修复路径。
- Beta → Release 迁移期间锁定源 Agent/Scheduler/Kopia 锁，旧版写入被阻止。
- 任务租约全链路原子化：项目占用与租约同事务；stale worker 不能 finish/retry；
  “过期 + 进程死亡”双条件才可回收；双 Service 竞争只产生一个快照。
- 最新云端版本不可读时清除其 verified 状态并在列表中保留损坏占位。
- 项目状态始终由最新快照推导，旧上传回调不再覆盖。
- 发布/GC 期间不长期持有本地 Kopia 仓库锁。
- 迁移中断后 staging 自动回收，源目录完好可重试。
- `workflow_dispatch` 手动发布支持完整产物上传与发布。
- 回归门禁：除 4 项登记的环境用例外，任何 XCTSkip 都使门禁失败。

## Beta 已知限制

- **本包为 ad-hoc 签名，未公证**：Gatekeeper 会拦截，需右键打开或去除隔离属性。
  公证需要 Developer ID Application 证书（见下）。
- **未启用 App Sandbox / iCloud entitlement**：只能使用「本地镜像」模式；
  真实 iCloud 双 Mac 验收尚未执行。
- **Stable 发布被门禁阻断**：需要（1）真实双 Mac iCloud 验收报告
  （`Scripts/require_icloud_acceptance.sh` 已拒绝空模板），（2）Developer ID
  签名 + 公证通过 `Scripts/verify_release.sh`。
- 后台代理注册（SMAppService）需要正式签名。
- FSEvents 实时触发、无变化跳过快照、XPC 仍未实现。

## 关于公证（Stable 路径）

Stable 打包脚本已支持与 AgentSpace 相同的公证链路：Developer ID 签名（Hardened
Runtime + 安全时间戳）→ notarytool 提交（keychain profile 或 APPLE_ID/PASSWORD）
→ staple app → 用 stapled app 重打 DMG → 公证并 staple DMG → `spctl`/stapler 校验。
启用只需一次性配置：

```bash
# 1. 申请 Developer ID Application 证书（当前 Apple Distribution 不能用于公证分发）
# 2. 存储公证凭据（本机当前缺失）：
xcrun notarytool store-credentials codetime-notary \
  --apple-id <apple-id> --team-id U8U443D7ZL
# 3. 之后打 stable tag（v1.0.0，不带后缀）即自动走签名+公证+验收门禁流程
```
