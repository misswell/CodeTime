# CodeTime 1.0.0 Beta 3

**这是开发者预览版，不是稳定版。不要把 CodeTime 作为唯一的代码备份。**

相对 Beta 2，Beta 3 完成了第七轮独立 Code Review 整改（CT-117…CT-128），核心是
**覆盖恢复前的保护副本绝不再因自动清理而失效**。自动化测试从 154 项扩展到
166 项，回归门禁覆盖 CT-001…CT-128 并强制校验测试报告一致性。

支持 macOS 14+，本包为 arm64 + x86_64 universal，内置 Kopia 0.23.1。
本包同时提供 `.zip` 与 `.dmg`（拖拽安装）两种格式。

## 安装

1. 下载 `CodeTime-1.0.0-beta.3-macos-universal.dmg`（或 `.zip`）。
2. 将 `CodeTime.app` 拖到「应用程序」。
3. 首次打开如被 Gatekeeper 拦截：右键 →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeTime.app
   ```

4. 首次启动会生成恢复密钥。请立即离线保存；丢失它且 Keychain 不可用时，备份无法解密。

## Beta 2 → Beta 3 修复（P1 + P2）

### P1 · 数据安全：保护副本不再被自动清理删除

- 覆盖恢复前创建的保护副本，在其自身触发的容量清理中**绝不会被删除**
  （CT-117，含真实 3GiB 稀疏文件规模变体）。
- 单个副本超过每项目 2 GiB 预算时**保留副本并显式上报超额**，预算是软上限（CT-118）。
- 容量清理永不删除项目**最新**的有效保护副本，也永不删除**正在被恢复任务引用**的副本
  （CT-121、CT-122）。
- 创建副本失败会**显式中止覆盖恢复**并记录原因；任何清理删除都会记录对象、字节与原因。

### P2 · 保护副本完整性

- 目录保护副本以**源目录与副本的独立树摘要**双向校验（相对路径 + 大小 + 内容哈希 +
  符号链接条目），复制前后各校验一次；源内容在复制期间持续变化时重试一次后**中止**，
  不再把不确定的副本当作可靠备份（CT-119）。
- 副本引入生命周期（verifying → verified / invalid）；不完整的副本永远不会被当作有效保护记录。
- 损坏的副本会被定期校验发现并在磁盘上标记 invalid，不再出现在有效列表中（CT-120）。

### P2 · 云端完整性校验

- 校验按**唯一 SHA-256 对象**去重：重复内容的文件只完整哈希一次，恢复过程复用校验结果
  （CT-123），大仓库校验与恢复显著减少重复读取。
- 校验结果报告文件引用数、唯一对象数与已校验字节数；同一哈希的引用大小不一致会被拒绝。

### P2 · 多设备身份

- 设备身份锚定 IOPlatformUUID：**macOS 迁移助理**把数据克隆到另一台 Mac 时，新机器会
  换发独立设备身份，旧设备的云端仓库原样保留（CT-124）。
- 双设备并发发布与 GC 语义经模拟验证：一台设备执行 GC 不会删除另一台设备已提交引用的对象
  （CT-125、CT-126，双设备模拟；真实双 Mac iCloud 验收仍未执行，见下）。

### P2 · 发布质量

- 测试报告以机器可读块为唯一事实源，三份工程文档的统计一致性由门禁强制校验；
  跳过项计入通过或绑定错误 Commit 会直接阻断发布（CT-127、CT-128）。

## 仍未验证（NOT RUN，不声称通过）

- 真实 iCloud 双 Mac 发布/恢复验收（需要两台真实 Mac 与同一 iCloud 账号）。
- 真实 Keychain 跨签名迁移（需要 Developer ID 真机环境）。
- 磁盘写满故障注入（CT-044，需要可控 ENOSPC 卷）。

## 已知限制

- Beta 构建未启用 App Sandbox / iCloud entitlement，只能使用「本地镜像」。
- 云端清理对多设备采用保守策略：检测到其他设备的仓库时跳过物理删除。
- 调度为后台轮询，并非 FSEvents 实时监听。
