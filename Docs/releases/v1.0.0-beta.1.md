# CodeTime 1.0.0 Beta 1

**这是开发者预览版，不是稳定版。不要把 CodeTime 作为唯一的代码备份。**

CodeTime 是一个 macOS 原生代码时间机器：选择代码目录后按计划创建 Kopia 加密快照，
把不可变对象和加密清单同步到 iCloud Drive 或本地镜像，并允许按时间点浏览、比较和恢复。

## 安装

1. 下载 `CodeTime-1.0.0-beta.1-macos-universal.zip` 并解压。
2. 将 `CodeTime.app` 拖到「应用程序」。
3. 首次打开如被 Gatekeeper 拦截：右键 →「打开」，或执行：

   ```bash
   xattr -dr com.apple.quarantine /Applications/CodeTime.app
   ```

4. 首次启动会生成恢复密钥。请立即离线保存；丢失它且 Keychain 不可用时，备份无法解密。

支持 macOS 14+，本包为 arm64 + x86_64 universal，内置 Kopia 0.23.1。

## Beta 已修复

- 时间轴按最新快照在前显示，避免把最旧版本当成“当前”并触发重复备份。
- 时间轴使用项目级快照列表，恢复前校验快照归属，避免跨项目写入。
- 恢复弹窗分离“副本目标”和“覆盖目标”，切换模式不会误用项目文件路径。
- 恢复密钥解析只移除开头的 `CT1`，正文包含该片段不再破坏密钥。
- 根锚定排除规则（以 `/` 开头）保留锚点，预览与 Kopia 实际排除一致。
- Keychain 读取失败不再静默生成新密钥；已有仓库时要求恢复凭据。
- 随机数生成失败会报错，不再可能生成全零密钥/盐。

## Beta 已知限制

- **云端清理仍有风险**：不可读的版本清单可能被跳过，其对象存在被清理的可能；在修复前不要依赖云端清理释放空间。
- **真实 iCloud 未验收**：本包没有 App Sandbox / iCloud entitlement，只能使用「本地镜像」。iCloud 逐出文件、上传确认、跨设备恢复尚未在真实容器上验证。
- **未签名/未公证**：ad-hoc 签名，Gatekeeper 会拦截；没有 Developer ID 证书。
- **UI 未完成人工视觉验收**：构建会话中主机锁屏，未能截图/点击验收。
- **后台代理注册**：`SMAppService` 注册需要正式签名，Beta 中可能失败。
- 未实现 FSEvents 实时触发、无变化跳过快照、XPC；定时/手动/唤醒补跑可用。
- 恢复/校验/差异的边界场景（超大文件、损坏对象、并发删除）仍未全部覆盖。
