# CodeTime 快速开始

CodeTime 自动保存你代码项目的历史版本：误删文件、改错代码、误操作，都能回到任意时间点。

## 三步开始

1. **选择备份位置**：安装后 CodeTime 会自动检测 iCloud。可用时点「启用 iCloud 备份」即可，**不需要选择文件夹**；不可用时会告诉你具体原因（未登录 Apple 账户 / 未开启 iCloud Drive / 当前预览版不支持 / 目录不可写），也可以直接用「仅使用本机备份」。
2. **选择项目**：CodeTime 会列出常见开发目录下的 Git 仓库供勾选，也可以「选择文件夹…」一次添加多个。只读取你选择的目录。
3. **保存恢复密钥**：首次启动会显示恢复密钥，请保存到密码管理器。换 Mac 恢复时需要它；它不会自动上传到 iCloud。

首次备份会自动开始：
- 先创建**本地加密快照**（`本地备份已完成`）；
- 再上传到 iCloud，只有**对象上传确认并发布版本清单**后，才会显示 `已上传到 iCloud`。

## 日常使用

- **时间机器**：浏览任意历史版本、单文件预览与恢复。
- **项目**：每个项目独立显示「本地备份」与「iCloud 同步」状态；云端失败不会影响本地备份，可点「立即重试」。
- **恢复记录 / 活动记录**：查看历史恢复与备份日志。

## 换 Mac / 重装

1. 安装 CodeTime，登录同一 Apple 账户。
2. 打开「从云端恢复…」：CodeTime 会自动找到 `iCloud Drive / CodeTime`，无需手动选目录。
3. 输入恢复密钥 → 选择设备与版本 → 恢复并校验。

## 隐私与安全

- 备份内容在上传前加密（AES-256-GCM），iCloud 中只有不可变加密对象与加密清单。
- 恢复密钥只显示在本机，不会写入日志、不会上传。
- 云端清理默认只生成预览；物理删除需要你明确确认（多设备安全策略）。

## 如果 iCloud 不可用

CodeTime 不会因为 iCloud 不可用而阻止使用：本地备份始终可用。修复方式：

系统设置 → Apple 账户 → iCloud → 打开 iCloud Drive；或在设置 → 备份位置点「重新检测」。


## 遇到问题先自检

```bash
Scripts/doctor.sh
```

它会指出缺什么、下一步做什么（开发者协议、描述文件、公证密码、iCloud Drive、屏幕锁定等）。
